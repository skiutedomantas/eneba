# GameHub frontend

The React, TypeScript, Vite, Tailwind CSS, and React Router application.

From this directory:

```sh
npm install
npm run dev
npm run build
npm run lint
```

During development, Vite proxies `/api/v1` to `http://127.0.0.1:8000` by default. Override the target with `API_PROXY_TARGET` when the PHP API runs elsewhere. See the [root README](../README.md) for full-stack setup.
